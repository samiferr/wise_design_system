Color follows text

Every icon is stroked with currentColor, so it takes the color of whatever contains it — including through a theme switch, with no icon-specific styling.

{% lucide "clock" size=15 %} muted {% lucide "check" size=15 %} action {% lucide "alert-triangle" size=15 %} danger

Adding an icon

Drop the SVG into wise_core/static/wise_core/icons/lucide/, named <name>.svg. The tag reads it from disk and caches it, so no registry needs updating.

{% lucide "info" size=16 cls="callout-icon" %}
An unknown name renders an HTML comment rather than raising — a missing icon never breaks a page. If an icon is silently absent, check the filename against the gallery below.
