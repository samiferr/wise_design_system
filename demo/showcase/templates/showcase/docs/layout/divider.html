When not to use one

{% lucide "info" size=16 cls="callout-icon" %}
Most separation in this system is already carried by borders — .card, .data-table rows, .form-actions, .accordion-item all draw their own. Adding a divider next to one of those gives you a double line. Reach for a divider only where nothing else provides the break.
