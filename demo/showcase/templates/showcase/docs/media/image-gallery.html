{% extends 'showcase/docs/_base.html' %} {% load wise_icons %} {% block doc_title_tag %}Image Gallery{% endblock %} {% block doc_section %}Media{% endblock %} {% block doc_title %}Image Gallery{% endblock %} {% block doc_intro %} A record's photos - a product's, a listing's - as one large image the visitor swipes through. From 640px up a strip of clickable thumbnails sits beneath it; on a phone the strip gives way to small indicator dots, the current one stretched into a pill. The view builds it: WiseImageGalleryMixin reads the images off the record and the template only includes one partial. {% endblock %} {% block doc_body %}

Use cases

  • A product page's photos: several angles of one thing, browsed in place.
  • Any detail page whose record has a set of images - a property, a vehicle, an inspection report.
  • Not for unrelated slides or a marketing rotation - use the Carousel - and not for a single image, which is just an Image.

Basic

Click a thumbnail, or focus the image and use the arrow keys. Narrow the window below 640px and the thumbnails turn into dots; swipe the image to move.

class ProductImage(models.Model):

from wise_core.mixins import WiseDetailView, WiseImageGalleryMixin

class ProductDetailView(WiseImageGalleryMixin, WiseDetailView):
    model = Product
    gallery_images = 'images'               # product.images.all()
    gallery_alt_field = 'alt_text'          # falls back to str(product)
    gallery_ordering = ('position', 'pk')
    gallery_label = 'Product images'{% endverbatim %}{% endfilter %}

Thumbnail rail

gallery_thumbnail_position = 'start' stands the thumbnails in a column beside the image from 1024px up (still a strip beneath it on a tablet, still dots on a phone). This one is also gallery_aspect_ratio = (4, 3) and opens on its second photo, as ?image=2 would.

No images yet

A record without photos keeps the stage's shape and says so, so the page lays out the same either way. With one photo there is nothing to choose between: no thumbnails, no dots.

Without a view

The mixin wraps wise_core.gallery.build_image_gallery(). Call it yourself when the images don't hang off a view's object - it takes model instances, dicts or plain URL strings, which is how the previews on this page are built.

    variant.photos.all(), gallery_id=f'variant-{variant.pk}-gallery',

Behaviour

  • The stage is CSS scroll-snap, so it swipes natively on touch with no library.
  • Thumbnails are anchors to each slide's id: with JavaScript off they still jump to their image. common.js makes the jump scroll only the stage, and keeps the selected thumbnail and dot in step while the visitor swipes.
  • The stage is focusable: arrow keys move one image (mirrored in right-to-left pages), Home and End go to the first and last.
  • The dots are an indicator, not a control (8px is too small to tap); swiping is the control on a phone. They are hidden from assistive technology, which hears each slide's "2 of 5" instead.
  • The stage's shape is fixed by gallery_aspect_ratio before any photo loads, and photos after the first load lazily.

{% filter force_escape %}{% verbatim %}Use the Wise Design System's Image Gallery to show a record's photos (a product's images, say). Rules:
- Build it in the view, not the template: add wise_core.mixins.WiseImageGalleryMixin before the detail view class (e.g. class ProductDetailView(WiseImageGalleryMixin, WiseDetailView)) and configure it with attributes: gallery_images (related manager name on the object, default 'images'), gallery_image_field ('image'), gallery_alt_field (e.g. 'alt_text'), gallery_thumbnail_field (optional), gallery_ordering (e.g. ('position', 'pk')), gallery_aspect_ratio ('1 / 1' or (4, 3)), gallery_fit ('contain' | 'cover'), gallery_thumbnail_position ('bottom' | 'start'), gallery_label (accessible name).
- Render it with exactly one include: {% include 'wise_core/components/_image_gallery.html' %} (or `with gallery=other` for a second gallery built with wise_core.gallery.build_image_gallery()). Never hand-write .gallery markup.
- Behaviour comes for free: thumbnails on 640px and up, indicator dots on phones, swipe via CSS scroll-snap, arrow keys on the focused stage, ?image=N opens the Nth image, an empty record shows a placeholder.
- Don't add arrows, autoplay, or a JS carousel library; don't style the thumbnails' selected state yourself (it is the accent border already).{% endverbatim %}{% endfilter %}
