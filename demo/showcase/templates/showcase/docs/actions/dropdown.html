Built on <details> so it opens, closes and traps nothing — no JavaScript required, and it degrades to an always-visible list if CSS fails to load. {% endblock %} {% block doc_body %}

Use cases

  • A menu of actions anchored to a trigger button - a per-row "more actions" menu (view/edit/export/delete) in a datatable.
  • A settings/kebab menu on a page header, with an icon-only trigger.
  • Grouping related actions with dividers and headers (e.g. "This record" vs "Export") inside one menu.
  • Not for primary page navigation - use a proper nav component (Sidebar, Topbar, Tab Group) for that instead.

Items that perform an action

A menu item that changes data should be a real form submission, not a link — a GET that mutates state will eventually be triggered by a crawler or a prefetch. .dropdown-item styles a <button> identically to an anchor.

Closing on outside click

<details> stays open until its summary is clicked again. If you want click-away to close it, common.js ships one delegated listener that closes any open dropdown when the click lands elsewhere — no per-dropdown wiring. 

{% filter force_escape %}{% verbatim %}document.addEventListener('click', function (e) {
    document.querySelectorAll('details.dropdown[open]').forEach(function (d) {
        if (!d.contains(e.target)) d.removeAttribute('open')
    })
}){% endverbatim %}{% endfilter %}
