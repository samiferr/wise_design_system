Use cases

  • An inline trend indicator next to a KPI number or in a datatable cell, where a full chart with axes would be too heavy.
  • Showing the recent direction of a metric (last 7/30 days) without needing exact values read off it.
  • A compact dashboard summary row where many small trends need to fit in a tight space.
  • Not a replacement for a full Line Chart when the user actually needs to hover for exact values, compare multiple series, or read axis labels.

Keep it honest

{% lucide "alert-triangle" size=16 cls="callout-icon" %}
Each sparkline is scaled to its own range, so two of them side by side are not comparable — a line that climbs steeply may be moving by three units. Always show the actual number next to it, and pass a shared scales override if rows must be compared.
