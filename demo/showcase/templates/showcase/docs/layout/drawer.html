Accessibility

{% lucide "alert-triangle" size=16 cls="callout-icon" %}
Unlike <dialog>, a drawer gets no focus trapping for free. Give it role="dialog" and an aria-label, move focus into it on open, and return focus to the trigger on close — or use a dialog if the interaction really is modal.
