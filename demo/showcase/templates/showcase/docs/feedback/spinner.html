Use cases

  • A short, indeterminate wait with no known duration or size - a button's own loading state, a modal fetching data, an inline async check.
  • Inside a disabled submit button while a form POST is in flight, so the user gets feedback that their click registered.
  • A small inline loading indicator next to a label (e.g. "Saving...") rather than blocking the whole page.
  • When the remaining work or duration IS known, use a Progress Bar or Progress Ring instead - they tell the user far more.

Reduced motion

Under prefers-reduced-motion the spin slows from 0.7s to 2s rather than stopping — a frozen spinner reads as a hung page, which is worse than a slow one. 

{% filter force_escape %}{% verbatim %}@media (prefers-reduced-motion: reduce) {
    .spinner { animation-duration: 2s; }
}{% endverbatim %}{% endfilter %}
