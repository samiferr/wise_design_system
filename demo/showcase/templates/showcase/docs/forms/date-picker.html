Picking from a calendar

When the choice depends on what is on each day — a booking screen, a shift roster — a dropdown picker is the wrong shape. Render the month grid server-side and make each day a link or a radio.

Constraining the range

min and max grey out impossible dates in the native picker. As always, they are a hint — the field validator is what enforces it. 

{% filter force_escape %}{% verbatim %}from django.utils import timezone

class BookingForm(forms.Form):
    day = forms.DateField(
        widget=forms.DateInput(attrs={
            "type": "date",
            "min": timezone.localdate().isoformat(),
        }),
    )

    def clean_day(self):
        day = self.cleaned_data["day"]
        if day < timezone.localdate():
            raise ValidationError("Pick a date in the future.")
        return day{% endverbatim %}{% endfilter %}

If you must add a JS picker

Keep it progressive: start from a working type="date" input and enhance it, so the form still submits if the script fails. Style the popup with the system's tokens (--color-panel, --color-divider, --z-dropdown) so it themes with everything else.
