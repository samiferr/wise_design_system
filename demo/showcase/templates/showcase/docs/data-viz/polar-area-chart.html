Use cases

  • Cyclical categories where the order around the circle is itself meaningful - months, days of the week, compass directions.
  • Comparing magnitude across those categories while keeping every slice's angle equal, unlike a Pie Chart.
  • A visually distinctive alternative to a Bar Chart for the same categorical data, when the circular layout reinforces the cyclical meaning.
  • Not for unordered, non-cyclical categories - a Bar Chart or Pie Chart reads more naturally there.

Radius, not area, but scaled honestly

Chart.js scales a polar-area slice's radius by the square root of its value internally, the same correction the old server-computed bubble and polar-area geometry made by hand - a doubled value gets a radius that reads as twice as big, not four times as big.

The bubble chart needs the same correction applied manually, since Chart.js takes its radius as a literal pixel value rather than scaling it for you.

Polar area or bar?

{% lucide "info" size=16 cls="callout-icon" %}
A bar chart is easier to read for almost any comparison — length is judged far more accurately than area. Choose a polar area chart when the circular arrangement carries meaning (a yearly cycle, a compass) and you want that structure visible, not because it looks more interesting.
