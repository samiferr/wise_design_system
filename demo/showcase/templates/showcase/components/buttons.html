Disabled

A native disabled attribute dims the button and blocks pointer events. On an <a>, which has no disabled attribute, use the btn-disabled class instead so it stays visually consistent and inert.

Icon buttons

.btn-icon squares off the button to a fixed 36×36 box for a single icon (no visible label) — pair it with a color modifier, or leave it bare for a plain outlined icon button like the row actions on a datatable.

.large-button sets a 250px minimum width — useful for a lone primary action at the bottom of a narrow form or modal.

Reference

ClassUse
btnBase class — always required, always paired with one color modifier below.
btn-primaryThe default call-to-action color (action-600).
btn-brandBrand-colored alternative primary action.
btn-secondaryOutlined, neutral — "Cancel", secondary actions.
btn-dangerDestructive actions (delete, revoke).
btn-ghostBorderless, tinted on hover — compact row-level actions.
btn-iconFixed 36×36 square, no text label, for a single icon.
btn-disabledVisually-disabled, inert state for an <a> (which has no disabled attribute).
large-button250px minimum width.
