The parent's primary key lives in the URL, which is what keeps the child views scoped, secure and able to redirect back where the user came from. {% endblock %} {% block doc_body %}

The URL shape

Nest the child routes under the parent. This single decision does most of the work: the parent is always available, the queryset is always scoped, and "back" is always obvious. 

{% filter force_escape %}{% verbatim %}urlpatterns = [
    path('categories//',                    CategoryDetailView.as_view(),  name='category_detail_view'),

    # children, always under their parent
    path('categories//products/',                 ProductListView.as_view(),    name='category_product_list'),
    path('categories//products/create/',          ProductCreateView.as_view(),  name='category_product_create'),
    path('categories//products//',        ProductDetailView.as_view(),  name='category_product_detail'),
    path('categories//products//update/', ProductUpdateView.as_view(),  name='category_product_update'),
    path('categories//products//delete/', ProductDeleteView.as_view(),  name='category_product_delete'),
]{% endverbatim %}{% endfilter %}

One mixin does the scoping

{% filter force_escape %}{% verbatim %}class ChildOfCategoryMixin:
    """Resolves the parent once and scopes every child query to it."""

    @cached_property
    def parent(self):
        return get_object_or_404(Category, pk=self.kwargs['parent_pk'])

    def get_queryset(self):
        # Scoping here means /categories/1/products/99/ 404s when product 99
        # belongs to another category - rather than quietly editing it.
        return super().get_queryset().filter(category=self.parent)

    def get_context_data(self, **kwargs):
        return {**super().get_context_data(**kwargs), 'parent': self.parent}

    def get_success_url(self):
        return reverse('category_product_list', args=[self.parent.pk]){% endverbatim %}{% endfilter %}

Scope the queryset, not just the template
Filtering by the parent in get_queryset() is what makes the child views secure. Looking the child up by pk alone and only displaying the parent lets anyone edit any record by guessing an id.

The five views

{% filter force_escape %}{% verbatim %}class ProductListView(ChildOfCategoryMixin, WiseListView):
    model = Product
    template_name = 'showcase/product/list.html'
    paginate_by = 10

class ProductDetailView(ChildOfCategoryMixin, WiseDetailView):
    model = Product
    template_name = 'showcase/product/detail.html'

class ProductCreateView(ChildOfCategoryMixin, WiseCreateView):
    model = Product
    form_class = ProductForm
    template_name = 'showcase/product/form.html'
    success_message = 'Product "%(name)s" created.'

    def form_valid(self, form):
        form.instance.category = self.parent   # the parent is never user input
        return super().form_valid(form)

class ProductUpdateView(ChildOfCategoryMixin, WiseUpdateView):
    model = Product
    form_class = ProductForm
    template_name = 'showcase/product/form.html'
    success_message = 'Product "%(name)s" updated.'

class ProductDeleteView(ChildOfCategoryMixin, WiseDeleteView):
    model = Product
    template_name = 'showcase/product/confirm_delete.html'
    success_message = 'Product deleted.'{% endverbatim %}{% endfilter %}

Setting form.instance.category in form_valid — rather than exposing a category field on the form — means the parent cannot be reassigned by posting a different value.

Deleting the parent

Say what will be destroyed. on_delete=CASCADE quietly removing dozens of children is the kind of surprise that costs trust.

Editing children inline

When children are small and always edited together — order lines, say — a Django inlineformset_factory avoids a page per row. Render each form as a .form-stack-compact inside a table row. 

{% filter force_escape %}{% verbatim %}ProductFormSet = inlineformset_factory(
    Category, Product, form=ProductForm, extra=1, can_delete=True,
)

class CategoryUpdateView(WiseUpdateView):
    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        context['formset'] = ProductFormSet(self.request.POST or None, instance=self.object)
        return context

    def form_valid(self, form):
        formset = ProductFormSet(self.request.POST, instance=form.instance)
        if not formset.is_valid():
            return self.form_invalid(form)
        response = super().form_valid(form)
        formset.save()
        return response{% endverbatim %}{% endfilter %}
