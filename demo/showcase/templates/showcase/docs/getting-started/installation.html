There is no npm package to depend on at runtime and no JS bundler — Tailwind's CLI compiles one stylesheet, and Django serves it as an ordinary static file. {% endblock %} {% block doc_body %}

1. Add the apps

Copy wise_core/ (and optionally wise_autocomplete/ and wise_richtext/) next to your own apps, then register them. wise_core is the only required one. 

{% filter force_escape %}{% verbatim %}INSTALLED_APPS = [
    # ...
    'django.contrib.humanize',   # used by some generic templates
    'django_filters',            # required by WiseListView's filtering
    'rest_framework',            # only if you use AutocompleteInputWidget

    'wise_core',
    'wise_autocomplete',         # optional
    'wise_richtext',             # optional
]{% endverbatim %}{% endfilter %}

2. Register the context processor

wise_core.context_processors.nav feeds the sidebar menu from a plain setting. Skip it only if you never render nav_menu.html. 

{% filter force_escape %}{% verbatim %}TEMPLATES = [{
    'BACKEND': 'django.template.backends.django.DjangoTemplates',
    'APP_DIRS': True,
    'OPTIONS': {'context_processors': [
        'django.template.context_processors.request',   # required
        'django.contrib.auth.context_processors.auth',
        'django.contrib.messages.context_processors.messages',
        'wise_core.context_processors.nav',
    ]},
}]{% endverbatim %}{% endfilter %}

3. Build the stylesheet

tokens.css is a partial, not an entry point — it has no @import "tailwindcss" and no @source of its own, because those depend on where your templates live. Your project supplies an entry file: 

{% filter force_escape %}{% verbatim %}/* static_src/input.css */
@import "tailwindcss";

/* Tell Tailwind where to scan for class names - including every wise_* app,
   since their component markup uses utility classes too. */
@source "../myapp/templates";
@source "../../wise_core/templates";
@source "../../wise_autocomplete/templates";
@source "../../wise_richtext/templates";

@import "../../wise_core/static/wise_core/css/tokens.css";{% endverbatim %}{% endfilter %}
{% filter force_escape %}{% verbatim %}npm install -D @tailwindcss/cli tailwindcss
npx tailwindcss -i ./static_src/input.css \
                -o ./wise_core/static/wise_core/css/tailwind.css --minify{% endverbatim %}{% endfilter %}
Forgetting an @source line is the single most common setup mistake: the build succeeds, but any utility class used only in that directory is tree-shaken out and the page renders unstyled.
