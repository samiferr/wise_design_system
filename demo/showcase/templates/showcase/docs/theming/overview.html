Why it works

This is the whole mechanism. A utility class is not a literal color; it is a pointer to a variable: 

{% filter force_escape %}{% verbatim %}/* what Tailwind v4 emits for bg-panel */
.bg-panel { background-color: var(--color-panel); }

/* ...and for a component rule that @applies it */
.card { border-color: var(--color-divider); background-color: var(--color-panel); }{% endverbatim %}{% endfilter %}

Redefine --color-panel under a selector and every card, table, dropdown and drawer follows instantly — including ones in application templates the design system has never seen.

Three independent axes

Each is one attribute on <html>, and they compose freely — a compact dark violet UI is a valid combination.

AttributeValuesChanges
data-themelight (default), darkNeutral ramp, surfaces, shadows, on-colors.
data-palettegreen (default), blue, violet, amberBrand and action ramps only.
data-densitycomfortable (default), compactControl heights, form and table rhythm.
