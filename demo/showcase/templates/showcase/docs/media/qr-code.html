Use cases

  • A scannable link to a record's detail page printed on a physical label, badge, or packaging.
  • Encoding a product SKU, invoice number, or asset tag as a barcode for warehouse/inventory scanning.
  • Any machine-readable code that must render server-side as crisp, scalable SVG rather than a rasterized image.
  • A project that never renders a code needs to install nothing extra - both tags degrade to a harmless HTML comment when their optional dependency isn't installed.

{% filter force_escape %}{% verbatim %}Use the Wise Design System's {% qr_code %} / {% barcode %} template tags to render machine-readable codes server-side as inline SVG - do not pull in a client-side JS QR/barcode library. Rules:
- Load once per template: {% load wise_codes %}.
- QR code: {% qr_code request.build_absolute_uri %} (wrap the result in a `.qr-code` container, or let the tag do it - check the tag's own output before double-wrapping).
- Barcode: {% barcode product.sku symbology="code128" write_text=True %}.
- Both tags delegate to small, optional pure-Python libraries (segno for QR, python-barcode for barcodes) rather than reimplementing the encodings - and neither is a hard dependency of wise_core, so a project that never renders a code installs nothing extra.
- If the optional library isn't installed, the tag degrades to an empty/harmless output rather than raising - check {% qr_code_available %} / {% barcode_available %} if you need to conditionally show a fallback message instead of silently rendering nothing.
- Rendered as SVG with shape-rendering: crispEdges, so the modules stay crisp at any zoom level - never rasterize it to a PNG for on-screen display.{% endverbatim %}{% endfilter %}
