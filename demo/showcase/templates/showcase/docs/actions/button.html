It works on both <button> and <a> — use a button for an in-page action (form submit, JS handler) and an anchor for navigation. {% endblock %} {% block doc_body %}

Use cases

  • Any in-page action that submits a form or runs a JS handler - use a real
  • Navigation that looks like a button (e.g. a prominent "New" call to action) - use an with the same classes.
  • A datatable row action (edit/delete icon) - use the compact, borderless btn-ghost variant instead of a full-size button.
  • A submit control mid-request - pair btn-primary with disabled and an inline Spinner for a loading state.
  • A single-icon control with no visible label (search, add, filter) - use btn-icon, and always add an aria-label.
