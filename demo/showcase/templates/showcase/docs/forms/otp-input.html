Validation

OTPField is a MultiValueField with require_all_fields=False, so a half-filled code produces one "enter all 6 digits" error rather than six "this field is required" errors — which is what you'd get from the naive implementation.

{% filter force_escape %}{% verbatim %}def compress(self, data_list):
    code = "".join((d or "").strip() for d in data_list)
    if not code:
        return ""
    if len(code) != self.length or not re.fullmatch(r"\d+", code):
        raise ValidationError("Enter all %(n)d digits of the code.",
                              params={"n": self.length})
    return code{% endverbatim %}{% endfilter %}

Autofill

Only the first box carries autocomplete="one-time-code". Putting it on every box makes browsers offer to fill the whole code into each one.

Verifying it

{% filter force_escape %}{% verbatim %}class VerifyView(FormView):
    form_class = VerifyForm
    template_name = "accounts/verify.html"

    def form_valid(self, form):
        code = form.cleaned_data["verification_code"]
        if not self.request.user.check_otp(code):
            form.add_error("verification_code", "That code is not valid or has expired.")
            return self.form_invalid(form)
        return super().form_valid(form){% endverbatim %}{% endfilter %}
