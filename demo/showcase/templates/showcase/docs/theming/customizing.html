Rebranding

{% filter force_escape %}{% verbatim %}/* your-project/static_src/input.css */
@import "tailwindcss";

@source "../myapp/templates";
@source "../../wise_core/templates";

@import "../../wise_core/static/wise_core/css/tokens.css";

/* Imported AFTER the system's tokens, so these win. */
@theme {
    --color-accent-background: #7c3aed;
    --color-accent-background-hover: #6d28d9;
    --color-accent-background-down: #5b21b6;
    --color-accent-content: #6d28d9;
    --color-focus-ring: #7c3aed;
}{% endverbatim %}{% endfilter %}

Check contrast when you retune a ramp
Buttons paint their label with --color-on-accent (white) over --color-accent-background, and links use --color-accent-content on the page. Keep 4.5:1 for both in light and dark - or, better, add the hue to the palette generator, which checks it for you. If your fill is light, set --color-on-accent to a dark value too, or button labels will wash out.

Bringing back rounded corners

The component layer never hardcodes a radius — it only reads the scale (the --corner-radius-* tokens). Override the Tailwind radii, or the corner tokens themselves, and every component rounds off at once. 

{% filter force_escape %}{% verbatim %}@theme {
    --radius-md: 0.75rem;
    --radius-lg: 1rem;
    --radius-xl: 1.25rem;
}{% endverbatim %}{% endfilter %}

Adding a theme of your own

A theme is just an attribute selector redefining tokens. Add one, and wiseSetTheme('sepia') switches to it — no other wiring needed. 

{% filter force_escape %}{% verbatim %}:root[data-theme="sepia"] {
    --color-background-base: #f4ecd8;
    --color-background-layer-1: #fbf6ea;
    --color-background-layer-2: #fbf6ea;
    --color-border-subtle: rgba(89, 74, 48, 0.22);
    --color-content-heading: #3b2f1c;
    --color-content-subdued: #6b5a3e;
}{% endverbatim %}{% endfilter %}
A custom theme registers the same way.

Overriding a component

Prefer changing a token — it propagates. Reach for a rule override only when one component genuinely needs to differ, and put it in your own CSS, after the import. 

{% filter force_escape %}{% verbatim %}/* Only this project's cards get a heavier border. */
@layer components {
    .card { border-width: 2px; }
}{% endverbatim %}{% endfilter %}

Adding a component

Build it from tokens, not literals, so it inherits theming for free. That is the whole contract: read var(--color-*) (directly or through a utility) and your component themes exactly like the shipped ones. 

{% filter force_escape %}{% verbatim %}@layer components {
    .stat-tile {
        @apply border border-border-subtle bg-background-layer-2 p-4;
    }
    .stat-tile-value {
        @apply font-heading text-heading-xl text-accent-content;
    }
    .stat-tile-label {
        @apply text-detail-s text-content-subdued;
    }
}{% endverbatim %}{% endfilter %}
