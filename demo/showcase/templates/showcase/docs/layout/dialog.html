Use cases

  • A focused, blocking task that must be completed or cancelled before returning to the page - a delete confirmation, a quick create form.
  • Content that needs the browser's own focus trapping and Esc-to-close, without a routed page navigation.
  • A short interaction that interrupts the current flow on purpose - if the work happens alongside the page instead, use a Drawer.
  • Not for a long form or content the user browses alongside other page content - a Drawer feels less like an interruption for that.

Use showModal(), not the open attribute
<dialog open> renders inline with no backdrop, no focus trap and no top-layer promotion. wiseOpenDialog() calls showModal(), which is what makes it an actual modal.

Dialog or drawer?

A dialog interrupts and demands an answer — confirm, or a short focused form. A drawer is for working alongside the page: filters, details, a long form. Use a dialog when the user should not continue until they respond.
