{% load static i18n %} {% comment %} Syntax highlighting and copy buttons for every `.doc-code` block on the page. Shared by the docs shell (showcase/docs/_base.html) and the marketing home page (showcase/marketing/_base.html), which both show `.doc-code` examples, so the setup lives in one include instead of two copies drifting apart. Prism.js (vendored - see static/showcase/js/vendor/prism/NOTICE.md) supplies the `.token` spans `.doc-code`'s CSS colors in demo/static_src/input.css. highlightAll() walks the DOM for text content regardless of which .doc-example tab panel is currently hidden, so a code panel is fully highlighted even before its tab is ever clicked. Load order matters: markup-templating and clike are grammars the later ones (django, javascript) extend or hook into, so they load first. The copy button is added here, once, for every `.doc-code` block on the page rather than by hand in each doc template - with 70+ examples across the site, a per-template checklist item is one a new page eventually misses. It runs after highlightAll() so `pre.textContent` copies the plain code, not Prism's `` wrapper markup. {% endcomment %}
