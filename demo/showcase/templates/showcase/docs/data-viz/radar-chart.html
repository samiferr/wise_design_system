Use cases

  • A profile across several axes at once - skill ratings, survey dimensions, capability scores for one subject.
  • Comparing one or two overlaid subjects' shapes against each other (e.g. this candidate vs the role's target profile).
  • Cases where the overall shape matters more than reading off precise individual values.
  • Not for more than two overlaid datasets or for precise value comparison - overlapping shapes get unreadable fast, and a Bar Chart reads exact values far better.

Zero baseline by default

charts.radar_chart() sets the radial scale's beginAtZero, so it scales from 0, not from the series minimum. A radar chart is read as "how full is each spoke", so anchoring to the smallest value would draw the weakest axis as empty no matter how high the actual score was.

Two series

Give radar_chart() a second dataset to overlay a second shape. Two is the practical limit — three overlapping shapes stop being readable. 

{% filter force_escape %}{% verbatim %}charts.radar_chart(dimensions, [
    charts.dataset("Before", before_scores, index=5, fill=False),
    charts.dataset("After", after_scores, index=0, fill=True),
], plugins={"legend": {"display": True}}){% endverbatim %}{% endfilter %}

Limits

{% lucide "alert-triangle" size=16 cls="callout-icon" %}
Radar charts distort: the enclosed area depends on the order of the axes, so reordering them changes the apparent size without any data changing. They also read poorly below three or above about eight axes. If precise comparison matters, a bar chart is more honest.
