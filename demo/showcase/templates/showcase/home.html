Why teams reach for it

Built for the app you already have

Not a component playground you glue onto a React frontend — a CSS layer and a set of Django class-based views meant to sit directly on top of your models.

{% lucide "settings" size=20 cls="text-action-600" %}

Tokens, not magic numbers

Theme, palette, density, corner radius, card shadow and background are each one CSS custom property, switched by one HTML attribute — no second stylesheet, no rebuild.

{% lucide "activity" size=20 cls="text-action-600" %}

Django-native, not a JS framework

Datatables, autocomplete and rich text are thin JS layers over a real Django form field or class-based view — django-filter and DRF do the work.

{% lucide "zap" size=20 cls="text-action-600" %}

Dark mode, four palettes, zero rebuild

Dark mode inverts the whole neutral ramp rather than tinting the light theme, so every existing text-gray-600 lands the right way up automatically.

What's in the box

Three installable apps, one demo site

wise_core

Tokens & components

Design tokens, the component CSS layer, base.html, generic CRUD templates, the {% templatetag openblock %} lucide {% templatetag closeblock %} icon tag and the Wise*View class-based view mixins.

wise_autocomplete

Search-as-you-type

AutocompleteInputWidget (DRF-backed) and AutoSuggestInputWidget (client-side filter over a JS array).

wise_richtext

Rich text editing

RichTextInputWidget, a Quill-backed form widget for a real Django model field.
