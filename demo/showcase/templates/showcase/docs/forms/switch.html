Use it for a setting that reads as "on/off"; use a checkbox for something being selected or agreed to. {% endblock %} {% block doc_body %}

Use cases

  • A setting that reads as a clear on/off state and applies immediately (e.g. "Email notifications", "Dark mode").
  • A profile or preferences page with several independent boolean settings shown as a list of toggles.
  • Anywhere a checkbox's implied "takes effect on submit" semantics would be misleading for what's actually an instant toggle.
  • For something being selected or agreed to as part of a larger form (not an isolated on/off setting), use Checkbox instead.

When the switch is not wrapped in a visible <label> — as in the row layout above — give it an aria-label, or it is announced as an unnamed checkbox.

Applying immediately

A switch usually implies the change takes effect at once. Post it rather than waiting for a Save button — and keep it a real form post so it works without JS.
