Column ordering

Sorting is a query parameter, applied to the queryset — not a client-side re-sort, which would only reorder the current page and silently lie about the rest.

{% filter force_escape %}{% verbatim %}class CategoryListView(WiseListView):
    model = Category
    ORDERABLE = {"name", "created_at"}      # allowlist - never trust the raw param

    def get_queryset(self):
        qs = super().get_queryset()
        sort = self.request.GET.get("sort", "name")
        field = sort.lstrip("-")
        if field in self.ORDERABLE:
            qs = qs.order_by(sort)
        return qs{% endverbatim %}{% endfilter %}
{% lucide "alert-triangle" size=16 cls="callout-icon" %}
Allowlist the sortable fields
Passing request.GET["sort"] straight into order_by() lets a visitor order by any field or traverse relations — a slow-query and information-disclosure hazard. And always include a deterministic tiebreak (a final "pk"), or pagination will repeat and skip rows across pages.
