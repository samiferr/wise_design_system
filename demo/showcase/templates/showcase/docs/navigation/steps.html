Round markers joined by a line that fills as the steps are finished - Spectrum's Steplist - which collapses to the current step's label on a phone. {% endblock %} {% block doc_body %}

Use cases

  • A record created in several screens - identity, contact, documents - where each screen saves its answers for the next.
  • A checkout, an import or a scan flow, where the visitor needs to know how far along they are and what is left.
  • Not for switching between views of one record (use Tabs) or for "page 2 of 9" of a long list (use Pagination): steps are an ordered path the visitor walks once.

A step is upcoming by default, .step-current is the one the visitor is on (also give it aria-current="step") and .step-done is finished: a green tick instead of its number, and the line after it filled in. The state is never colour alone - the number, the tick and the bold label say the same thing.

From a view

wise_core.steps.wizard_steps() turns the labels and the index of the current step into the list _steps.html renders, so a wizard view never writes the states by hand. 

{% filter force_escape %}{% verbatim %}from wise_core.steps import wizard_steps

class NewPatientStepView(...):
    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        context['steps'] = wizard_steps(
            [_('Identity'), _('Contact'), _('Document'), _('Review')],
            current=self.step_index,
        )
        return context{% endverbatim %}{% endfilter %}

Going back to a finished step

Pass urls to wizard_steps() and a finished step's label becomes a link back to it. Leave the entry None where going back is not allowed - a step whose answers were already saved, say.

On a phone

Below the sm breakpoint only the current step keeps its label; the others shrink to their marker on the line (their labels stay for assistive technology). The bar therefore stays on one row however many steps there are, and the visitor still reads "where am I" from the one label that remains. Resize this window to see it.

Moving the marks from a script

Each marker holds both its number and its tick (data-role="step-number" / "step-done"), one of them hidden, and each step is keyed by data-step. A single-page flow - the card-scanning dialog is one - moves along by toggling step-current / step-done on the li and hidden on the two spans; no markup is rebuilt.

Reference

Class / keyUse
stepsThe <ol>. Give it an aria-label.
stepOne step (<li>); upcoming by default.
step-currentThe step the visitor is on; add aria-current="step".
step-doneA finished step: green marker, filled line after it.
step-markerThe round marker: the step's number, or a tick once done.
step-labelThe step's name; an <a> when a finished step can be revisited.
wizard_steps(labels, current, urls=None, keys=None)Builds the list _steps.html takes: label, state, number, key, url.
