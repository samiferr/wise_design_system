Computing it

{% filter force_escape %}{% verbatim %}class ImportJob(models.Model):
    total_rows = models.PositiveIntegerField(default=0)
    processed_rows = models.PositiveIntegerField(default=0)

    @property
    def percent(self):
        if not self.total_rows:
            return 0
        return round(self.processed_rows / self.total_rows * 100){% endverbatim %}{% endfilter %}

Indeterminate

.progress-bar — a different class — is the animated strip shown when there is no percentage to report. The autocomplete widget uses it while a request is in flight.

Two similar names, two different jobs
.progress + .progress-value is the determinate bar. .progress-bar on its own is the indeterminate animation — it predates the determinate one and is kept under its original name so the autocomplete widget keeps working.

Polling for updates

For a long job, a meta refresh is the no-JS option; a small fetch loop against a JSON endpoint is the better one. Either way the percentage is computed server-side. 

{% filter force_escape %}{% verbatim %}async function pollProgress(url, el) {
    const {percent, done} = await (await fetch(url)).json()
    el.style.setProperty('--value', percent + '%')
    if (!done) setTimeout(() => pollProgress(url, el), 2000)
