With both attributes set, the browser derives an aspect ratio and reserves the space before the file loads. Tailwind's reset makes images fluid (max-width:100%), so the attributes act as a ratio hint, not a fixed size.

Uploads of unknown shape

User uploads are never the aspect ratio your layout wants. Constrain the box and let the image cover it, rather than stretching it.

Alt text

Describe what the image conveys, not that it is an image. If it is decorative and the surrounding text already says everything, use alt="" so it is skipped rather than read as a filename.
