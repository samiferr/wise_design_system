Radius

The default (no data-radius attribute) zeroes the whole radius scale, so every rounded-* utility resolves to a square corner with no template changes — this system's baseline look. data-radius="soft" and data-radius="round" retune the same scale to non-zero values instead; nothing in the component layer hardcodes a radius, every rule below reads this scale, so the whole UI moves together. Card shadow

.card is flat by default — it separates from the page with a border, not a shadow — because a page full of shadowed cards reads as noisy. --shadow-card (declared as none in the @theme block) is the one token that controls it, retuned by data-shadow against the same blueprint scale above so "elevated" cards still look consistent with the dropdown/dialog/toast shadows.

Background

data-bg retunes the neutral page/surface trio (--color-page, --color-panel-alt, --color-surface) toward a warm or cool cast, independently of data-palette — palette moves the brand/action ramps, this moves the ground they sit on. --color-panel never moves, so raised content still reads as raised in every combination.

Six axes, one panel
Theme, palette, density, radius, shadow and background all switch this way — one attribute on <html>, persisted to localStorage. The demo app's sidebar (and this site's own header) opens the same settings panel these buttons drive individually — see wise_core/components/_settings_panel.html.
