As a form field

_form_fields.html detects a checkbox widget and switches to the horizontal layout automatically — you don't select it yourself. 

{% filter force_escape %}{% verbatim %}subscribe = forms.BooleanField(required=False, initial=True, label="Subscribe to updates"){% endverbatim %}{% endfilter %}
{% lucide "alert-triangle" size=16 cls="callout-icon" %}
A BooleanField that is required=True means "must be ticked" — which is what you want for a terms checkbox, and almost never what you want otherwise. Use required=False for ordinary optional flags.

Indeterminate

For a "select all" that reflects a partial selection. It is a DOM property, not an attribute, so it can only be set from script. 

{% filter force_escape %}{% verbatim %}document.querySelector('#select-all').indeterminate = someButNotAllChecked{% endverbatim %}{% endfilter %}
