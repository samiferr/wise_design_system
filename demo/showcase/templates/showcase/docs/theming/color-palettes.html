Switch palette

Each palette is a different seed; every role below regenerates from it. Baseline is the M3 default, #6750A4.

Accent roles

Always pair a role with its on- role. Primary is for the most prominent actions, secondary for less prominent ones (tonal buttons, selected navigation, filter chips), tertiary for contrasting accents, and error for destructive and error states only.

Rebranding
Add your seed to PALETTES in scripts/generate_m3_palettes.mjs and run npm run build:palettes && npm run build:css. Contrast between every role and its on- role is guaranteed by the tone mapping, whatever seed you pick.
