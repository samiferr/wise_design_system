Zero baseline by default

charts.radar() scales from 0, not from the series minimum. A radar chart is read as "how full is each spoke", so anchoring to the smallest value would draw the weakest axis as empty no matter how high the actual score was. 

{% filter force_escape %}{% verbatim %}charts.radar(scores)                    # 0 .. max(scores)
charts.radar(scores, maximum=10)        # fixed 0..10 scale - use this to
                                        # compare two subjects fairly{% endverbatim %}{% endfilter %}

Limits

{% lucide "alert-triangle" size=16 cls="callout-icon" %}
Radar charts distort: the enclosed area depends on the order of the axes, so reordering them changes the apparent size without any data changing. They also read poorly below three or above about eight axes. If precise comparison matters, a bar chart is more honest.
