Use cases

  • A wide toolbar or tab bar on narrow viewports that must scroll horizontally instead of wrapping.
  • A row of tiles or thumbnails that should snap into place as the user scrolls (e.g. a category strip).
  • The base substrate for a Carousel - reach for the Scroller directly when you just need a constrained, snapping scroll region without carousel controls.
  • A vertical variant for a fixed-height list that should snap between items on scroll.
