What each slice carries

charts.pie() returns everything the wedge and its legend entry need, so the template loops once over one list rather than zipping several together.

KeyValue
pathThe wedge, as an SVG d.
colorA var(--color-*) reference from the series palette.
labelThe matching label, if you passed any.
value / percentThe raw value and its share, rounded to one decimal.

Edge cases handled for you

A single value covering the whole circle cannot be drawn as one arc — the start and end points coincide and browsers render nothing. _arc_path detects that and emits two half arcs instead. Zero and negative values are skipped rather than producing inverted wedges.

100% — two arcs, not one.

Accessibility

Colour alone should never be the only way to tell slices apart. The legend carries the labels and percentages, so keep it — and give the <svg> a role="img" with a summarising aria-label.
