Independent axis scaling

Both axes scale to their own data range by default, so the cloud fills the plot whatever the units — a price in the hundreds against a count in the tens still spreads out. Pass scales to fix either axis when the absolute range matters. 

{% filter force_escape %}{% verbatim %}charts.scatter_points([(0, 0), (10, 100), (5, 50)])
# [{'x': 0, 'y': 0}, {'x': 10, 'y': 100}, {'x': 5, 'y': 50}]{% endverbatim %}{% endfilter %}

Labelling points

Chart.js's own tooltip already shows each point's (x, y) on hover - give a dataset a label and that's the whole legend and tooltip caption needed for one series.

Overplotting

{% lucide "info" size=16 cls="callout-icon" %}
With many points, identical values stack invisibly and the chart understates density. Shrink pointRadius or add translucency with charts.dataset(..., color=charts.color_alpha(color, 0.6)) so overlaps darken, or bin the data server-side before plotting.
