Use cases

  • Any multi-line text field - notes, addresses, descriptions, comments.
  • Content that needs to stay plain text (no formatting) - use Rich Text Input instead if the content genuinely needs structure like headings or lists.
  • A field where the user should control its height (vertical resize) without being able to widen it and break the form layout.
