Rebranding

{% filter force_escape %}{% verbatim %}/* your-project/static_src/input.css */
@import "tailwindcss";

@source "../myapp/templates";
@source "../../wise_core/templates";

@import "../../wise_core/static/wise_core/css/tokens.css";

/* Imported AFTER the system's tokens, so these win. */
@theme {
    --color-brand-500: #7c3aed;
    --color-brand-600: #6d28d9;
    --color-brand-700: #5b21b6;
    --color-action-500: #7c3aed;
    --color-action-600: #6d28d9;
    --color-action-700: #5b21b6;
}{% endverbatim %}{% endfilter %}

Check contrast when you retune a ramp
Buttons paint their label with --color-on-action over --color-action-600. If your new 600 is light, set --color-on-action to a dark value too, or button labels will wash out.

Bringing back rounded corners

The component layer never hardcodes a radius — it only reads the scale. Restore Tailwind's defaults and every component rounds off at once. 

{% filter force_escape %}{% verbatim %}@theme {
    --radius-sm: 0.125rem;
    --radius-md: 0.375rem;
    --radius-lg: 0.5rem;
    --radius-xl: 0.75rem;
}{% endverbatim %}{% endfilter %}

Adding a theme of your own

A theme is just an attribute selector redefining tokens. Add one, and wiseSetTheme('sepia') switches to it — no other wiring needed. 

{% filter force_escape %}{% verbatim %}:root[data-theme="sepia"] {
    --color-page: #f4ecd8;
    --color-panel: #fbf6ea;
    --color-panel-alt: #efe5cd;
    --color-divider: rgba(89, 74, 48, 0.22);
    --color-gray-900: #3b2f1c;
    --color-gray-600: #6b5a3e;
}{% endverbatim %}{% endfilter %}
A custom theme registers the same way.

Overriding a component

Prefer changing a token — it propagates. Reach for a rule override only when one component genuinely needs to differ, and put it in your own CSS, after the import. 

{% filter force_escape %}{% verbatim %}/* Only this project's cards get a heavier border. */
@layer components {
    .card { border-width: 2px; }
}{% endverbatim %}{% endfilter %}

Adding a component

Build it from tokens, not literals, so it inherits theming for free. That is the whole contract: read var(--color-*) (directly or through a utility) and your component themes exactly like the shipped ones. 

{% filter force_escape %}{% verbatim %}@layer components {
    .stat-tile {
        @apply border border-divider bg-panel p-4;
    }
    .stat-tile-value {
        @apply font-heading text-3xl font-semibold text-action-600;
    }
    .stat-tile-label {
        @apply text-xs uppercase tracking-wider text-gray-600;
    }
}{% endverbatim %}{% endfilter %}
