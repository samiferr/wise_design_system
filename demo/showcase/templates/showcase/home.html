Wise Design System

A Tailwind CSS v4 design system for Django projects, extracted from the DCMS7 application. Complex components — datatables, autocomplete, rich text — are backed by Django itself and its ecosystem (django-filter, Django REST Framework), not a JS framework. This site is both its documentation and its own demo: everything on it is built with the components it describes.
