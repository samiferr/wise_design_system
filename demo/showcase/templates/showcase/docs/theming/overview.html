Tailwind v4 compiles every color utility to a var(--color-*) reference, so changing a token's value re-themes everything built on it — at runtime, with no rebuild. {% endblock %} {% block doc_body %}

Why it works

This is the whole mechanism. A utility class is not a literal color; it is a pointer to a variable: 

{% filter force_escape %}{% verbatim %}/* what Tailwind v4 emits for bg-primary */
.bg-primary { background-color: var(--color-primary); }

/* which is the Material 3 system role... */
--color-primary: var(--md-sys-color-primary);

/* ...which points at a tone of the generated palette */
:root                   { --md-sys-color-primary: var(--md-ref-palette-primary40); }
:root[data-theme=dark]  { --md-sys-color-primary: var(--md-ref-palette-primary80); }{% endverbatim %}{% endfilter %}

Swap the palette's tones (data-palette) or which tone each role reads (data-theme) and every button, card, menu and sheet follows instantly — including ones in application templates the design system has never seen.

Six independent axes

Each is one attribute on <html>, and they compose freely — a compact dark blue UI with sharp corners and a warm background is a valid combination.

AttributeValuesChanges
data-themelight (default), darkWhich palette tone every M3 color role reads.
data-palettebaseline (default, M3 #6750A4), green, blue, amberThe seed color - every generated tonal palette.
data-densitycomfortable (default), compactField, button, list-item and table heights.
data-radiusM3 shape scale (default), soft, sharpThe whole M3 corner scale — buttons, cards, fields, dialogs…
data-shadowflat (default), soft, elevatedOutlined vs. elevated cards and panels.
data-bgtonal (default), warm, coolThe neutral palettes behind every surface role.

See Design Tokens for shape, elevation and background in depth. All six are one settings panel — see wise_core/components/_settings_panel.html, opened from the icon next to the brand in this site's own sidebar and the demo app's. Its Copy tokens tab turns whatever combination you land on into a paste-ready <html data-*> line plus the resolved :root { --token: value; } block behind it, via one .copy-button.
