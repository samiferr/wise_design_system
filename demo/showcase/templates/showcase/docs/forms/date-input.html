Django's DateInput does not emit type="date" by default
It renders type="text", so you get no calendar. Passing attrs={"type": "date"} is required — and on an update form you also need format="%Y-%m-%d", or the existing value renders in a locale format the input cannot parse and the field appears empty. 
{% filter force_escape %}{% verbatim %}class ProductForm(forms.ModelForm):
    class Meta:
        model = Product
        fields = ["name", "available_from"]
        widgets = {
            "available_from": forms.DateInput(
                attrs={"type": "date"},
                format="%Y-%m-%d",       # required for edit forms to prefill
            ),
        }{% endverbatim %}{% endfilter %}

Datetime and time

With USE_TZ = True, a datetime-local value has no timezone. Django interprets it in TIME_ZONE and stores UTC — so always render stored values through localtime rather than assuming they round-trip.
