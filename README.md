# wise_design_system
A Design System for Business project using Django

## Components

- **Autocomplete widget** (`wise_autocomplete/`) — `AutocompleteInputWidget` (DRF-backed search) and
  `AutoSuggestInputWidget` (client-side suggestions), extracted from
  [DCMS7](https://github.com/samiferr/DCMS7). See
  [`docs/autocomplete-widget.md`](docs/autocomplete-widget.md) for how to use it, and
  [`docs/autocomplete-widget-for-ai.md`](docs/autocomplete-widget-for-ai.md) for the AI-agent-facing
  reference.
