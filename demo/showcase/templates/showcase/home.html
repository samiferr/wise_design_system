Wise Design System

{% include 'wise_core/components/_theme_toggle.html' %}

A Tailwind CSS v4 design system for Django projects. Datatables, autocomplete widgets and rich text editing are backed by Django and its ecosystem — django-filter, Django REST Framework — not a JavaScript framework. The JS each widget ships is a thin layer over a real Django form field or class-based view.
