Use cases

  • A grid of navigational links or entry points (e.g. a settings hub, a picker of report types).
  • Dashboard summary tiles showing a metric, a chart, or a live-preview of current settings.
  • List items that carry more visual weight than a plain table row but don't need full datatable features (sorting, per-column filters).
  • Not a substitute for a Data Table when the content is genuinely tabular and needs sorting/scanning many rows at once - see the Card vs Table pattern doc.
