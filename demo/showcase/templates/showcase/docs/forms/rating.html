Use cases

  • Displaying an average or existing star rating read-only, e.g. on a product or review summary.
  • Letting a user submit their own star rating as part of a form - a review, a feedback form.
  • Any 1-5 (or similar small-scale) rating where a row of stars communicates faster than a number.
  • Not for a precise numeric score that needs finer granularity than a handful of discrete steps - use a Number Input for that instead.

rating = forms.ChoiceField(
    choices=[(i, str(i)) for i in range(1, 6)],
    widget=RatingInput(),
    initial=4,
)

# On a ModelForm:
class Meta:
    model = Product
    fields = ["name", "rating"]
    widgets = {"rating": RatingInput()}{% endverbatim %}{% endfilter %}

How the CSS-only highlight works

A sibling selector can only match elements after the checked input. So the widget emits the radios in descending order (5 first) and the container is flex-row-reverse, flipping them back to ascending on screen. Now input:checked ~ label matches exactly the stars visually to the left of the checked one. 

{% filter force_escape %}{% verbatim %}.rating-input {
    @apply inline-flex flex-row-reverse items-center justify-end gap-0.5;
}
.rating-input input { @apply sr-only; }

.rating-input input:checked ~ label,
.rating-input label:hover,
.rating-input label:hover ~ label {
    @apply text-warning-500;
}{% endverbatim %}{% endfilter %}
{% lucide "info" size=16 cls="callout-icon" %}
Because they are radios, the group is keyboard-navigable with arrow keys and the value posts like any other choice field. The inputs are .sr-only, not display:none, so they stay focusable.
