Use it to choose one value from five to about fifteen options when a radio group would take too much room. For actions rather than values, use the Menu; for a plain native control, the Select. {% endblock %} {% block doc_body %}

Use cases

  • Choosing a plan, role, status or country from a short, parallel list - with an optional description under each option.
  • A ChoiceField in a Django form, through the DropdownSelect widget.
  • Not for two or three options (use Radio), and not for a long or searchable list (use Combobox or Autocomplete).

Appearance

The button has no border: a #dadada fill-picker background and the chevron mark it as a control, which sets it apart from the bordered text field. Hover and the open state deepen the fill (fill-picker-hover); keyboard focus adds the 2px focus-ring; an invalid dropdown gets a thin red outline plus the error message; a disabled one uses fill-disabled. The popover is white (background-elevated), opens 8px below the button and scrolls past 240px. The chosen option is bold with a check.

    In a Django form

    wise_core.widgets.DropdownSelect renders this markup for any ChoiceField or ModelChoiceField. The value posts through a hidden input, so the field validates like a stock select, and _form_fields.html wraps it with the label, help text and errors. Choosing fires a bubbling change event on the hidden input. 

    {% filter force_escape %}{% verbatim %}from wise_core.widgets import DropdownSelect

class ProfileForm(forms.Form):
    plan = forms.ChoiceField(choices=PLANS, widget=DropdownSelect){% endverbatim %}{% endfilter %}

    Behavior

    Click, or press Up/Down on the button, to open. Up/Down/Home/End move the active option; Enter or Space chooses; Escape closes and returns focus to the button; Tab closes. Clicking elsewhere closes it too. Only one dropdown is open at a time.

    Do and don't

    • Keep option labels short and parallel, and give the field a visible label - the fill alone is a faint cue (about 1.4:1 on white).
    • Provide a placeholder that says what to do ("Select a country").
    • Don't use a dropdown for two or three options; use Radio.

    Reference

    ClassUse
    pickerThe wrapper (data-picker): button, popover and hidden input.
    picker-button / picker-valueThe borderless button; the chosen label (.is-placeholder when empty). aria-invalid="true" draws the outline.
    picker-popoverThe listbox (role="listbox", hidden until opened).
    picker-optionOne option (data-value, aria-selected, aria-disabled); .picker-option-label, .picker-option-desc, .picker-check inside.
    picker-groupA group heading inside the list.
