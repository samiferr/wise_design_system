Supplying wise_nav_sections

A context processor in your own project — nav_menu.html just reads it, it doesn't build it:

{% filter force_escape %}{% verbatim %}WISE_NAV_SECTIONS = [
    {
        'title': 'Catalog',
        'items': [
            {'label': 'Categories', 'url_name': 'category_list_view', 'icon': 'tag', 'match': 'category'},
            {'label': 'Products', 'url_name': 'product_list_view', 'icon': 'clipboard-list', 'match': 'product'},
        ],
    },
]{% endverbatim %}{% endfilter %}

Desktop vs. mobile

base.html renders this same nav_menu.html twice: once inside a fixed md:sticky column for desktop, and once inside wise_core/components/sidebar.html — a full-screen overlay toggled by the topbar's hamburger button — for mobile. The menu markup itself doesn't change between the two.
