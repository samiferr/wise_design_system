charts.dataset() pairs a label with its values and picks a color from the shared series palette; charts.bar_chart() wraps one or more datasets into a complete Chart.js config with the design system's grid and tick colors already applied.

Recoloring

Pass color to dataset() to override the palette.

{% filter force_escape %}{% verbatim %}charts.dataset("Revenue", revenue, color="var(--color-warning-400)"){% endverbatim %}{% endfilter %}

Grouped series

Give bar_chart() more than one dataset and Chart.js groups them automatically.

{% filter force_escape %}{% verbatim %}charts.bar_chart(months, [
    charts.dataset("This year", this_year, index=0),
    charts.dataset("Last year", last_year, index=1),
]){% endverbatim %}{% endfilter %}

Reading it accessibly

{% lucide "info" size=16 cls="callout-icon" %}
A <canvas> is opaque to screen readers - Chart.js draws pixels, not a DOM a reader can walk. Give it a role="img" with a summarizing aria-label, and put the same numbers in a table nearby for anyone who can't use the chart.
