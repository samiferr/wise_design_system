Rebranding — override without touching tokens.css

Tailwind v4 merges @theme blocks by variable name, so a second @theme block imported after tokens.css in your project's entry CSS wins — you never edit the vendored file itself. 

{% filter force_escape %}{% verbatim %}/* your-project/static_src/input.css */
@import "tailwindcss";
@import "path/to/wise_core/static/wise_core/css/tokens.css";

@theme {
    --color-brand-500: #7c3aed;
    --color-brand-600: #6d28d9;
    --color-action-500: #7c3aed;
    --color-action-600: #6d28d9;
}{% endverbatim %}{% endfilter %}

Typography

Headings use --font-heading (Barlow Condensed, semibold, tight leading); body text uses --font-body (Barlow). Both apply automatically to their elements — you only reach for the utility classes when a component has overridden the font and you need it back.
