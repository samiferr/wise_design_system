Building the weeks grid

Python's own calendar module already produces the 6×7 day grid — no extra dependency needed. Group your events by date, then annotate each day in the view: 

{% filter force_escape %}{% verbatim %}import calendar
from datetime import date

class ScheduleView(TemplateView):
    template_name = 'showcase/schedule.html'

    def get_context_data(self, **kwargs):
        today = date.today()
        year, month = today.year, today.month
        events_by_day = {e.date.day: [] for e in Event.objects.filter(date__year=year, date__month=month)}
        for e in Event.objects.filter(date__year=year, date__month=month):
            events_by_day.setdefault(e.date.day, []).append(e)

        cal = calendar.Calendar(firstweekday=6)  # Sunday first
        weeks = [
            [
                {
                    'number': day or '',
                    'is_outside': day == 0,
                    'is_today': day == today.day and month == today.month,
                    'events': events_by_day.get(day, []),
                }
                for day in week
            ]
            for week in cal.monthdayscalendar(year, month)
        ]
        return {**super().get_context_data(**kwargs), 'weeks': weeks}{% endverbatim %}{% endfilter %}

Just picking a date?

The full grid above is for a scheduling/booking view. For a plain "pick a date" field on a form, don't build a calendar at all — a native <input type="date"> already gets the standard Input treatment and the browser's own date picker for free.
