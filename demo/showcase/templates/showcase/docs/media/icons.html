Use cases

  • Any icon anywhere in the UI - nav items, buttons, badges, callouts, table cells - via the lucide template tag rather than an or icon font.
  • An icon that must inherit the surrounding text color (currentColor) and scale precisely to a pixel size.
  • An icon-only control, always paired with an aria-label since the icon itself has no accessible name.
  • Choosing a new icon: search lucide.dev for the closest match to keep the whole app visually consistent, rather than sourcing an icon from a different set.

Sizes and stroke

Match the icon to the control it sits in and never scale it with CSS — choose a size. The stroke is 2.4 on Lucide's 24-unit grid, so it is 2px at 20px and scales with the size. Only a glyph inside a small control is drawn heavier (stroke_width="2.6" for a chevron or sort arrow; tokens.css already does it for the built-in ones).

Status glyphs

Lucide has no filled set, so Lumen's four status glyphs are drawn here: a filled disc (a triangle for notice) with the glyph cut out. status_glyph renders them in currentColor; callouts, toasts and form alerts already do. They always sit next to a word — status is never an icon alone.

Color follows text

Every icon is stroked with currentColor, so it takes the color of whatever contains it — including through a theme switch, with no icon-specific styling.

Adding an icon

Drop the SVG into wise_core/static/wise_core/icons/lucide/, named <name>.svg, and keep the Lucide licence notice in that folder (ISC; some shapes derive from Feather, MIT). The tag reads it from disk and caches it, so no registry needs updating.
