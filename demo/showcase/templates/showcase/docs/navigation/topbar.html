Use cases

  • Automatically present on every authenticated page below the md breakpoint - not something you add per page.
  • Giving mobile users a hamburger toggle for the sidebar, since the full sidebar column is hidden on narrow screens.
  • Showing the signed-in user's name and the design-settings toggle on small screens, mirroring what the sidebar shows on desktop.
  • Not a place to add page-specific actions - those belong in the page's own list_actions/detail actions, not the topbar.

How the toggle works

No framework, just two small functions in common.js: openSideBar() shows #mySidebar (the mobile drawer rendered by wise_core/components/sidebar.html) and swaps the hamburger icon for a close icon; closeSideBar() reverses it, and also fires on window.onscroll so the drawer doesn't stay open while browsing underneath it.
