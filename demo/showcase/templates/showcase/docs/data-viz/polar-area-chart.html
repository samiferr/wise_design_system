Radius is scaled by area

A slice's radius is proportional to the square root of its value, not the value itself. Scaling radius linearly would make a doubled value cover four times the area, which the eye reads as four times bigger — the classic way to overstate a difference by accident. 

{% filter force_escape %}{% verbatim %}radius = math.sqrt(value / max_value) * outer_radius{% endverbatim %}{% endfilter %}

The bubble chart does the same thing for the same reason.

Polar area or bar?

{% lucide "info" size=16 cls="callout-icon" %}
A bar chart is easier to read for almost any comparison — length is judged far more accurately than area. Choose a polar area chart when the circular arrangement carries meaning (a yearly cycle, a compass) and you want that structure visible, not because it looks more interesting.
