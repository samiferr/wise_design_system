Fixing the scale

By default Chart.js's y axis starts at zero, which is usually right for a revenue-style series. Pass a scale override when a fixed range matters more than the auto-fit. 

{% filter force_escape %}{% verbatim %}charts.line_chart(months, [charts.dataset("Revenue", revenue)],
                  scales={"y": {"min": 0, "max": 120}})

# ...and to compare two series on one chart, give both datasets the same scale:
charts.line_chart(months, [
    charts.dataset("This year", this_year, index=0),
    charts.dataset("Last year", last_year, index=1),
], scales={"y": {"min": 0, "max": 120}}){% endverbatim %}{% endfilter %}

Multiple series

Give line_chart() more than one dataset. Each gets its own color from charts.series_color(i) automatically - or set color per dataset - and Chart.js's built-in legend labels them, so there is no legend markup to hand-author. 

{% filter force_escape %}{% verbatim %}charts.line_chart(months, [
    charts.dataset("This year", this_year, index=0, fill=True),
    charts.dataset("Last year", last_year, index=1),
], plugins={"legend": {"display": True}}){% endverbatim %}{% endfilter %}
