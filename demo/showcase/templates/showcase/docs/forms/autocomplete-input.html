The backend contract

The widget expects a paginated DRF list endpoint that honours a ?q= search parameter and exposes a detail route at <url>/<pk>/ — it uses the latter to resolve the label for an already-saved value when an edit form loads. 

{% filter force_escape %}{% verbatim %}# api.py
class CategoryViewSet(viewsets.ReadOnlyModelViewSet):
    serializer_class = CategorySerializer

    def get_queryset(self):
        qs = Category.objects.all()
        q = self.request.query_params.get("q")
        if q:
            qs = qs.filter(name__icontains=q)
        return qs

router = routers.DefaultRouter()
router.register("categories", CategoryViewSet, basename="category-api"){% endverbatim %}{% endfilter %}

The endpoint is a real API surface
It is queryable by anyone who can load the form. Apply the same permission and queryset filtering you would to any other view — restricting the widget in the template restricts nothing.

Scoping to a parent field

data-parent points at another field's input; its value is sent along so the results can be narrowed — cities within the selected country, products within the selected category. 

{% filter force_escape %}{% verbatim %}"product": AutocompleteInputWidget(attrs={
    "data-url": reverse_lazy("product-api-list"),
    "data-text_field": "name",
    "data-parent": "id_category",   # the parent field's input id
}){% endverbatim %}{% endfilter %}
