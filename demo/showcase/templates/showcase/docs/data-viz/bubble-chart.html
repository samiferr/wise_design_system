Always set an opacity — bubbles overlap by nature, and opaque ones hide each other entirely.

Size is scaled by area

Radius is proportional to the square root of the value. Doubling the radius would quadruple the visible area, so a linear mapping silently overstates large values — a genuinely common way for bubble charts to mislead. 

{% filter force_escape %}{% verbatim %}charts.bubbles([(1, 1, 1), (2, 2, 4)], max_radius=10)
# radii: [5.0, 10.0]   - a 4x value gives a 2x radius, hence 4x the area{% endverbatim %}{% endfilter %}

Three variables is a lot

{% lucide "alert-triangle" size=16 cls="callout-icon" %}
Position is read accurately; area is not. If the third variable is the one that matters, put it on an axis and use a scatter or bar chart instead — reserve bubbles for when size is genuinely secondary context.
