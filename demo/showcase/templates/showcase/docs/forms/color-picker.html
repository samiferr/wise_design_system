With a text field

The native control cannot be typed into. Pair it with a text input when users need to paste a brand hex.

Storing it

A CharField(max_length=7) holds #rrggbb. Validate it — the input always posts a well-formed value, but a crafted request will not. 

{% filter force_escape %}{% verbatim %}from django.core.validators import RegexValidator

color = models.CharField(
    max_length=7,
    default="#16a34a",
    validators=[RegexValidator(r"^#[0-9A-Fa-f]{6}$", "Enter a hex color like #16a34a.")],
){% endverbatim %}{% endfilter %}

Rendering the stored color

A user-chosen color is data, so it belongs in an inline style — it cannot be a Tailwind class, which must exist at build time. This is the pattern the Categories datatable uses.
