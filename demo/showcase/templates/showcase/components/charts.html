Sparkline / trend line

There's no CSS-only equivalent for a line chart — hand-author an inline <svg> with a <polyline>, the same way vendored icons are inline SVG. Compute the points attribute server-side from your series (each point is "x,y", y measured from the top, so a bigger value means a smaller y). 

{% filter force_escape %}{% verbatim %}{% endverbatim %}{% endfilter %}
{% filter force_escape %}{% verbatim %}def sparkline_points(values, width=100, height=30):
    lo, hi = min(values), max(values)
    span = (hi - lo) or 1
    step = width / (len(values) - 1)
    return ' '.join(
        f'{i * step:.0f},{height - ((v - lo) / span) * height:.0f}'
        for i, v in enumerate(values)
    ){% endverbatim %}{% endfilter %}
