{% extends 'showcase/docs/_base.html' %} {% load wise_icons %} {% block doc_title_tag %}Color Palettes{% endblock %} {% block doc_section %}Theming & Utilities{% endblock %} {% block doc_title %}Color Palettes{% endblock %} {% block doc_intro %} Lumen color is one neutral scale and eleven hue scales, each in numbered steps with a light and a dark value - so a step flips with the theme on its own. Semantic tokens pick steps out of them, and components only ever use semantic tokens (content-default, accent-background, negative-content, ...), which is why a palette or theme switch is always legible. The accent is one hue: blue by default, switchable to indigo, purple, green or amber. {% endblock %} {% block doc_body %}

Switch palette

A palette re-points the accent scale at another Lumen hue; every accent token below follows. Every Lumen hue is built to the same contrast ladder, so white text on the accent fill and the accent as link text hold 4.5:1 whichever one you pick, in both themes.

Layers & content

The page is background-base; raised panels are background-layer-1; cards and fields are background-layer-2; floating surfaces are background-elevated. Set text in content-default, headings in content-heading and secondary text in content-subdued. content-disabled is never used for live content. A control's own border is border-default (3:1 on the page) - border-subtle is for decorative dividers and card edges only.

Accent

Always pair a fill with its own on- token. accent-background fills the single main action and selected checkboxes, radios and switches; hover steps it one shade (accent-background-hover), press two (accent-background-down). accent-content colors links and selected text on a layer. In dark mode the filled accent steps one shade lighter. neutral-background is the solid neutral: pressed action buttons, tooltips, toasts.

Status

Four semantic families - informative, positive, notice and negative - each paired with an icon and a word, never color alone. The -background token fills a badge or button (text is on-accent, or on-notice on the orange fill); the -content token colors text and icons on a layer.

Palette steps

The reference tier underneath: --lumen-<hue>-<step>, generated into lumen-palettes.css by npm run build:palettes. Semantic tokens point at these - templates shouldn't, except for charts and illustration. The scales are gray, blue, red, orange, yellow, green, celery, cyan, indigo, purple, fuchsia and magenta. The accent scale --lumen-accent-<step> is whichever hue the palette switch selected.

Rebranding
Add a hue to ACCENTS in scripts/generate_lumen_palettes.mjs (it must exist in lumen-scales.json) and run npm run build:palettes && npm run build:css. The script checks the contrast of every token pair across both themes, every palette and every background, and refuses to write anything that fails.
