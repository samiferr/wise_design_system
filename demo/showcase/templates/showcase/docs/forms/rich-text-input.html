Rendering the stored HTML

{% lucide "alert-triangle" size=16 cls="callout-icon" %}
Never render it with |safe unsanitized
The field contains HTML supplied by whoever filled the form. Piping it straight through |safe is a stored-XSS vulnerability. Sanitize on the way in, with an allowlist, and treat the stored value as untrusted until you have. 
{% filter force_escape %}{% verbatim %}# pip install nh3
import nh3

def clean_notes(self):
    return nh3.clean(
        self.cleaned_data["notes"],
        tags={"p", "br", "strong", "em", "u", "ol", "ul", "li", "a", "h2", "h3", "blockquote"},
        attributes={"a": {"href", "title", "rel"}},
    ){% endverbatim %}{% endfilter %}
