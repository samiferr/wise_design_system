Use cases

  • A filter side-panel for a list/datatable page (the built-in filter-panel is a specialized right-hand drawer).
  • A record preview or quick-edit form that should stay alongside the underlying page rather than replace it.
  • A long form that would feel too disruptive as a blocking Dialog.
  • The design-settings panel pattern: any persistent, edge-anchored tool panel a user opens while continuing to see the page behind it.

Accessibility

{% lucide "alert-triangle" size=16 cls="callout-icon" %}
Unlike <dialog>, a drawer gets no focus trapping for free. Give it role="dialog" and an aria-label, move focus into it on open, and return focus to the trigger on close — or use a dialog if the interaction really is modal.
