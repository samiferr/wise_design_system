{% extends 'showcase/docs/_base.html' %} {% load wise_icons %} {% block doc_title_tag %}Callout{% endblock %} {% block doc_section %}Feedback{% endblock %} {% block doc_title %}Callout{% endblock %} {% block doc_intro %} A block-level message inside page content — a warning on a form, an explanation on a detail page. Unlike a toast, it is part of the document: it does not float, does not time out, and is there on page load. {% endblock %} {% block doc_body %}

Use cases

  • A warning on a form before a destructive action (e.g. deleting a category also deletes its products).
  • Contextual explanation embedded in page content, like a note on pricing or a policy that a reader needs before continuing.
  • A confirmation-page notice summarizing the consequences of an action the user is about to take.
  • Any message that should be part of the document flow, present on page load, and never auto-dismiss - if it should float and time out instead, use a Toast.

Accessibility

{% lucide "info" size=16 cls="callout-icon" %}
A callout present on page load needs no ARIA — it is read in document order. If you insert one in response to a user action, add role="alert" so it is announced.

- Base markup: a flex container with an icon and content:

- Tone modifiers (pick one, or omit for the neutral default): callout-info, callout-success, callout-warning, callout-danger.
- callout-icon marks the leading icon so it aligns to the first line; callout-title is optional bold first line - a one-line callout can skip it.
- Pick an icon that matches the tone: info -> "info", success -> "check", warning -> "alert-triangle", danger -> "circle-x".
- A callout present on page load needs no ARIA (read in document order). Only add role="alert" if you insert one dynamically in response to a user action.
- Never use this for a message that should auto-dismiss after a few seconds - use the Toast component for that instead.{% endverbatim %}{% endfilter %}
