Independent axis scaling

Both axes are scaled to their own range, so the cloud fills the plot whatever the units — a price in the hundreds against a count in the tens still spreads out. padding keeps points near the extremes from being clipped at the edge. 

{% filter force_escape %}{% verbatim %}charts.scatter([(0, 0), (10, 100), (5, 50)], 100, 60, padding=3)
# [{'cx': 3.0, 'cy': 57.0}, {'cx': 97.0, 'cy': 3.0}, {'cx': 50.0, 'cy': 30.0}]{% endverbatim %}{% endfilter %}

Labelling points

Zip the geometry back onto the records so each point can carry a tooltip or a link — the return order matches the input order. 

{% filter force_escape %}{% verbatim %}products = list(Product.objects.all())
geometry = charts.scatter([(p.price, p.units_sold) for p in products], 300, 140)
context["points"] = list(zip(products, geometry)){% endverbatim %}{% endfilter %}

SVG's own <title> gives a native tooltip and is announced by screen readers — no tooltip component needed.

Overplotting

{% lucide "info" size=16 cls="callout-icon" %}
With many points, identical values stack invisibly and the chart understates density. Drop the radius, add opacity="0.6" so overlaps darken, or bin the data server-side before plotting.
