Why it works

This is the whole mechanism. A utility class is not a literal color; it is a pointer to a variable: 

{% filter force_escape %}{% verbatim %}/* what Tailwind v4 emits for bg-accent-background */
.bg-accent-background { background-color: var(--color-accent-background); }

/* which is a Lumen semantic token, pointing at a step of the accent scale... */
:root                   { --color-accent-background: var(--lumen-accent-900); }
:root[data-theme=dark]  { --color-accent-background: var(--lumen-accent-800); }

/* ...which points at a hue of the generated palette */
:root                        { --lumen-accent-900: var(--lumen-blue-900); }
:root[data-palette="green"]  { --lumen-accent-900: var(--lumen-green-900); }{% endverbatim %}{% endfilter %}

Swap the accent hue (data-palette) or which step each token reads (data-theme) and every button, card, menu and sheet follows instantly — including ones in application templates the design system has never seen.

Five independent axes

Each is one attribute on <html>, and they compose freely — a compact dark green UI with sharp corners is a valid combination. The page background is not one of them: it is a fixed gray, so every surface and text color is checked against a single canvas.

AttributeValuesChanges
data-themelight (default), darkWhich palette step each semantic color token reads.
data-paletteblue (default), indigo, purple, green, amberThe accent hue - which Lumen scale the accent tokens read.
data-densitycomfortable (default), compactField, button, list-item and table heights (32px by default, 24px compact).
data-radiusLumen corner radii (default), soft, sharpThe whole corner scale — buttons, cards, fields, dialogs…
data-shadowflat (default), soft, elevatedOutlined vs. raised cards and panels.

See Design Tokens for shape, layers and shadow in depth. All five are one settings panel — see wise_core/components/_settings_panel.html, opened from the icon next to the brand in this site's own sidebar and the demo app's. Its Copy tokens tab turns whatever combination you land on into a paste-ready <html data-*> line plus the resolved :root { --token: value; } block behind it, via one .copy-button.
