Use cases

  • Choosing one option from a moderate-to-long list where showing every option as radios would be too much.
  • A ChoiceField/ModelChoiceField in a Django form - country, category, status.
  • Any field where native mobile picker behavior and full keyboard accessibility matter, with no JavaScript.
  • When the option list is too long to scroll comfortably or must be searched, use Combobox (client-side) or Autocomplete Input (server-side) instead.

Multiple

Multi-selects are hard to use — most people don't discover ctrl-click. Prefer a checkbox group unless the list is long.
