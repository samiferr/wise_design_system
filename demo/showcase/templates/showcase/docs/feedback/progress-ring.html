Use cases

  • A dashboard or summary tile where the percentage is the headline number (storage used, quota consumed, goal completion).
  • A compact circular indicator next to other stats, where a horizontal bar would take too much width.
  • Any place a completion percentage needs a label centered inside the indicator itself.
  • When the progress accompanies a specific task or list row rather than being the tile's main figure, prefer a Progress Bar instead.

How it works

The indicator circle is stroked with a dash pattern exactly as long as its circumference, then offset by the unfilled remainder. CSS rotates the SVG -90deg so the arc starts at twelve o'clock instead of three. 

{% filter force_escape %}{% verbatim %}circumference = 2 * math.pi * radius
dasharray  = circumference
dashoffset = circumference * (1 - percent / 100)   # 100% -> 0 offset -> full ring{% endverbatim %}{% endfilter %}

progress_ring() clamps its input to 0–100, so a bad percentage cannot produce a ring that over- or under-draws.

Ring or doughnut?

{% lucide "info" size=16 cls="callout-icon" %}
A progress ring shows one value against a maximum. To break a total into parts, use the doughnut chart instead.
