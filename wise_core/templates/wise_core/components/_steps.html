Pass `steps`, a list of dicts (`wise_core.steps.wizard_steps()` builds it from the labels and the current step): {'label': 'Identity', 'state': 'done'|'current'|'upcoming', 'number': 1, 'key': 'identity', 'url': '/...'} `url` (optional) makes a finished step's label a link back to it; `key` becomes `data-step`, for a script that moves the marks along as the visitor goes. Each marker carries both its number and its tick, one of them hidden, so such a script only has to toggle `hidden` (`data-role="step-number"` / `"step-done"`). The current step is `aria-current="step"` and a finished one's tick is announced as "Done", so the state is never colour alone. `label` (the `
