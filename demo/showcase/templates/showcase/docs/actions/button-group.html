Use it for a segmented choice or a cluster of actions on the same object — not as a general toolbar. {% endblock %} {% block doc_body %}

Use cases

  • A segmented choice among a small, fixed set of options - e.g. a Preview/Code or Card/Table view toggle.
  • A cluster of related actions on the same record that read better joined than spaced apart.
  • Anywhere you'd reach for a radio-button toggle rendered as buttons instead of native radio inputs.
  • Not a general toolbar - for a loose collection of unrelated actions, use separate buttons with normal spacing instead.
