min/max are a convenience, not a guarantee — they are trivially bypassed. Keep the validation on the field (min_value/max_value), which is what actually enforces it.

Money

Use DecimalField, never a float, and set step to the currency's smallest unit so the stepper doesn't produce unrepresentable values. 

{% filter force_escape %}{% verbatim %}price = forms.DecimalField(
    max_digits=9, decimal_places=2,
    widget=forms.NumberInput(attrs={"step": "0.01", "class": "input"}),
){% endverbatim %}{% endfilter %}
