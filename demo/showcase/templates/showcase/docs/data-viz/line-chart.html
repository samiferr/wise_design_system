Coordinates

SVG's y axis grows downward, so a larger value produces a smaller y — charts.polyline() handles the flip. padding insets the plot vertically so a stroked line's cap is not clipped at the top or bottom of the viewBox. 

{% filter force_escape %}{% verbatim %}charts.polyline([1, 3, 2], 100, 30)
# "0.00,30.00 50.00,0.00 100.00,15.00"   <- the peak (3) is at y=0{% endverbatim %}{% endfilter %}

Fixing the scale

By default the series is scaled to its own min and max, which exaggerates small variation. Pass an explicit range — usually a zero baseline — when the absolute size matters. 

{% filter force_escape %}{% verbatim %}charts.polyline(revenue, 300, 120, padding=6, minimum=0)

# ...and to compare two series on one chart, give both the same bounds:
lo, hi = 0, max(max(a), max(b))
line_a = charts.polyline(a, 300, 120, minimum=lo, maximum=hi)
line_b = charts.polyline(b, 300, 120, minimum=lo, maximum=hi){% endverbatim %}{% endfilter %}
