The last item is the current page, so it is a <span>, not a link — linking a page to itself is a dead end for keyboard and screen-reader users. CSS styles it as the emphasised one automatically.

Building it from data

{% filter force_escape %}{% verbatim %}# In the view
def get_context_data(self, **kwargs):
    context = super().get_context_data(**kwargs)
    context["crumbs"] = [
        {"label": "Categories", "url": reverse("category_list_view")},
        {"label": self.object.category.name, "url": self.object.category.get_absolute_url()},
        {"label": self.object.name, "url": None},   # current page
    ]
    return context{% endverbatim %}{% endfilter %}

Breadcrumb or back link?

{% lucide "info" size=16 cls="callout-icon" %}
At two levels deep, the plain Back link in .top-actions-header — what the generic detail template already renders — is usually enough. Breadcrumbs earn their space from three levels down, or when the hierarchy itself is information the user needs.
