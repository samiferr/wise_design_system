What the partial expects

_pagination.html reads page_obj from the context (the standard name Django's ListView/Paginator puts there) and preserves the current ?q= search param across page links. WiseListView supplies page_obj automatically once you set paginate_by. 

{% filter force_escape %}{% verbatim %}class CategoryListView(WiseListView):
    model = Category
    filterset_class = CategoryFilter
    template_name = 'showcase/category/list.html'
    paginate_by = 10{% endverbatim %}{% endfilter %}

Disabled ends

Prev./Next are individually disabled (via .disabled, not removed) at the first/last page so the row's width stays stable.
